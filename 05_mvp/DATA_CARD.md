# Ficha de datos

Llenar cada sección. Una sección que no aplica dice por qué.

## Fuente

Origen de los datos (enlace, institución, simulador o sistema real) y fecha de descarga.

## Licencia

Licencia de uso y si permite uso comercial.

## Contenido

Número de registros, variables y su tipo, variable objetivo y unidades.

## Recolección y preprocesamiento

Cómo se recolectaron los datos y qué transformaciones aplicó el equipo (limpieza, filtrado,
normalización, aumento de datos).

## División

Cómo se separan entrenamiento, validación y prueba, y cómo se evita la fuga de información entre
ellos.

## Sesgos y limitaciones

Poblaciones subrepresentadas, periodos o regiones que los datos no cubren y riesgos de usar el
modelo fuera de ese contexto.

## Datos personales

Si los datos contienen información personal, cómo se anonimizaron y con qué permiso se usan.
